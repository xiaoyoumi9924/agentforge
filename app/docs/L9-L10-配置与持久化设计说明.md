## 1. 配置管理（模块 ⑩）

来源优先级（后者覆盖前者）：

```
① 代码默认值 → ② af_config.json（工作目录） → ③ 环境变量（AF_* / OPENAI_*）
```

- `--config` 打印有效配置（密钥打码）；
- 环境变量清单：`AF_PROVIDER / OPENAI_BASE_URL / OPENAI_API_KEY / AF_MODEL /
  AF_LOG / AF_PLUGIN / AF_SESSION / AF_CONTEXT_WINDOW`；
- `af_config.json` 支持 provider / budget / sandbox / logPath / sessionId。

## 2. DPAPI 密钥（模块 ⑧ 的一部分）

- `--set-key <key>`：`CryptProtectData`（当前 Windows 用户凭据）加密 → 密文 Base64 落盘 `.af_secret`；
- `--clear-key`：删除密钥文件；
- 密钥优先级：`OPENAI_API_KEY` 环境变量 > `.af_secret` 文件；
- 密钥文件里**只有密文**，换用户/换机无法解密。

## 3. 会话持久化（模块 ⑫）

- SQLite（官方 amalgamation，`thirdparty/sqlite/sqlite3.c`，零额外依赖）；
- 表结构：
  - `sessions(id, title, updated_at)`
  - `messages(session_id, seq, role, content, tool_calls, tool_call_id, finish_reason)`
- 生命周期：启动时 `loadHistory(sessionId)` 恢复历史 → 跑完后 `appendMessages` 增量保存；
- 命令行：
  - `agent.exe --sessions` 列出会话；
  - `agent.exe --resume <session> "<任务>"` 恢复会话继续。
