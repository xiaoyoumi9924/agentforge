## 4. 质量指标

- 代码规模：`src/` 30 文件 4666 行；`gui/` 3 文件 468 行；`tests/` 10 文件 1185 行；`plugins/` 2 文件 269 行
- 文档：`docs/` 9 份、约 740 行（SRS/HLD/SDD + 各阶段设计说明）
- 自检用例：42 项（进程内，`agent.exe --selftest`）
- 依赖：零第三方框架（JSON 单头、SQLite 官方 amalgamation、WinHTTP 原生）

## 5. 已知局限（诚实清单）

1. **沙箱边界**：Job Object 提供进程树强杀/资源上限，但**不提供网络与文件系统内核边界**（如实写在 `--sandbox-check` 输出里）；
2. **索引为词法级**：未接 tree-sitter，符号抽取有误报（不追求语法完备性，见 L7-L8 文档）；
3. **增量更新未做**：索引全量重建（课程规模 <1s），会话为追加式；
4. **GUI diff 面板**为"参数+结果对照"，未做逐行 diff 高亮；
5. **模型联调**默认 MockLLM；真实 API 通过环境变量/DPAPI 密钥接入，未在评测中计费运行。

## 6. 复现命令

```powershell
./build.ps1 -Out agent.exe        # 构建 CLI
./build.ps1 -Target contract_check
./plugins/build_plugin.ps1        # 构建示例插件
./build_gui.ps1                   # 构建 Qt GUI
./tests/verify_L3.ps1 … verify_L11.ps1   # 各阶段验证
./tests/evaluate.ps1              # 回归评测
```
