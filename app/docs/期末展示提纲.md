# 期末展示提纲（10 分钟）

> 对齐课程考核要求：**完整设计文档、功能展示、关键策略、重点优化模块、Skills、Agent 配置**。
> 建议节奏：1 分钟定位 + 4 分钟演示 + 3 分钟讲策略 + 1 分钟分工与反思 + 1 分钟 Q&A 缓冲。

## 0. 开场（30 秒）

一句话定位：**AgentForge —— 让模型"看懂代码、修改代码、执行代码"的 Coder 类 AI Agent harness。**
演示载体：CLI `agent.exe` + Qt GUI `AgentForgeGUI.exe`。

## 1. 系统全景（1 分钟）

- 13 模块 / 3 层架构图（骨架.md 的落地情况表，见 `docs/总体状态.md`）
- 4 个核心机制：W1 上下文闭环 / W2 Agent 循环 / W3 工具调用协议 / W4 流式协议
- 迭代路线：L1 需求设计 → L2 契约 → L3 对话 → L4 工具 → L5 循环 → L6 安全 → L7-8 索引 → L9-10 配置/持久化 → L11 GUI → L12 评测

## 2. 功能演示（4 分钟，MockLLM 现场跑）

| 演示 | 命令/操作 | 展示点 |
|---|---|---|
| 流式对话 | `agent.exe "用一句话解释 SSE"` | SSE 逐 token、TTFB、usage 统计 |
| 读代码作答 | `agent.exe "读 mock_target.txt 并告诉我有哪些函数"` | 工具调用 → observation 回喂 → 依据作答 |
| 插件与权限门 | `agent.exe "用 WordCount 统计 …"`（AF_PLUGIN=…dll） | C ABI 插件、Ask 批准、拒绝则 fail-closed |
| 错误恢复 | 非法参数/未知工具任务 | 失败不崩、回喂"可用工具/缺少字段" |
| 上下文与检索 | `--index-stats` / `--index "AgentLoop"` | 符号索引、依赖边、检索命中 |
| 持久化 | `--sessions` / `--resume` | SQLite 会话恢复 |
| GUI | `build_gui\AgentForgeGUI.exe` | 对话、工具/diff 面板、命令面板、权限弹窗 |

（如需真实模型：`--set-key <key>` 后切换 `OPENAI_BASE_URL`，教师现场验证。）

## 3. 关键策略（3 分钟，挑 4 个讲）

1. **错误即数据**：工具失败/幻觉/非法参数一律作为 observation 回喂，循环自我修复（L4/L5 验证覆盖）；
2. **上下文分层 + 预算**：L0-L6 分层、顺序即缓存前缀、超预算降级链（全文→签名→符号名→路径→丢弃）；
3. **安全默认**：权限门 deny 永远赢 + fail-closed、Job Object 沙箱（进程树强杀/资源上限）、DPAPI 密钥、写路径围栏；
4. **可验证**：每讲都有验证脚本 + 进程内 selftest（42 项）+ 回归评测，MockLLM 零费用可重复。

## 4. 重点优化模块（1 分钟）

- `agent_loop.cpp`：六道闸门 + G8 消息守卫（孤儿 tool/配对断裂/只回一半的块级修复）；
- `context_budget.cpp`：预算数学 + 降级链 + 块级历史裁剪；
- `sandbox_win.cpp`：Job Object 能力自检如实报告"已强制/未强制"。

## 5. Skills 与 Agent 配置（1 分钟）

- **Skills（项目级）**：编译约定（build.ps1 一键）、提交约定（git）、验证约定（verify_L*.ps1 全绿才提交）——工具链细节沉淀为文档（见 `docs/Agent配置与Skills.md`）；
- **Agent 配置**：`af_config.json`（模型/预算/沙箱）+ 环境变量覆盖 + 权限规则表（Deny/Allow/Ask）。

## 6. 团队与反思（1 分钟）

- 分工：AI 执行局（生成设计/代码/测试）+ 组内审核验收（人机协同）；
- 反思：AI 能力边界——上下文管理靠人类外置状态（Turn/会话库），安全边界靠内核而非提示词，责任最终在人（课程 001 的"宪政"结论）。
