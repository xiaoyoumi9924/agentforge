# L7-L8 仓库索引与检索 —— 设计说明

| 项 | 内容 |
|---|---|
| 阶段 | L7-L8 · 仓库理解与索引（模块 ③）+ 检索接入上下文（W1） |
| 上游 | L5 ContextAssembler（L2 仓库地图 / L3 检索命中两层） |
| 代码 | `src/repo_index.{hpp,cpp}`、`src/main.cpp`（`--index-stats` / `--index` / 启动时建索引+检索） |
| 验收 | `tests/verify_L7.ps1`：selftest 31 PASS + 索引/检索/冒烟 10 PASS |

## 1. 轻量符号索引（不依赖 tree-sitter）

扫描 `.h/.hpp/.c/.cpp/.cc` 源码，词法级抽取：

| 抽取项 | 规则 | 用途 |
|---|---|---|
| 依赖边 | `#include <...>` / `#include "..."` | 依赖图 / 影响面分析 |
| 类型符号 | `class/struct/enum/namespace NAME` | 仓库地图、检索锚点 |
| 函数符号 | 行内 `NAME(...)` 且行尾以 `{ ; :` 收尾 | 检索命中位置，围绕它取片段 |
| 噪声过滤 | 排除 `if/for/while/return/...` 等控制语句 | 降低误报 |

**权衡**：误报（把调用当声明）比漏报便宜——误报只是多一行候选，漏报会让模型看不到关键代码。

## 2. 检索（W1 的检索端）

1. 用户输入按非标识符字符切词；
2. 对每个文件打分：文件名命中 +2/词、符号命中 +3/词；
3. 每个命中符号产出一个片段（符号行起 + maxLines 行，带行号）；
4. 无符号命中但文件名命中 → 给文件头部片段；
5. 按分数排序取 Top-K。

检索结果注入 `Turn::retrieved` → 经 `ContextAssembler` 进入 **L3 检索命中层**（受 25% 预算约束，超预算走降级链），仓库地图注入 **L2 层**。

## 3. 命令行演示

```powershell
./build/agent.exe --index-stats          # 索引统计 + 依赖边清单
./build/agent.exe --index "AgentLoop"    # 检索演示（打印命中片段）
./build/agent.exe "agent_loop.cpp 里的循环闸门有哪些？"   # 正常任务：自动检索+组装
```

## 4. 增量更新说明

本讲索引是"可重建缓存"：文件变化后重新 `build()` 即可，没有做 mtime 差量。
这是有意的取舍——课程规模（几十~几百文件）重建耗时 <1s，
增量更新的复杂度（文件监听/失效传播）留到需要时再加。
